# 遊創舎 ライブラリ管理ルール

■ ライブラリID

L-001 ～ L-999   LED Library
S-001 ～ S-999   Screen Library
P-001 ～ P-999   Particle Library
C-001 ～ C-999   Cabinet Library
R-001 ～ R-999   Reel Library
B-001 ～ B-999   Button Library
A-001 ～ A-999   Audio Library
D-001 ～ D-999   Demo Program

■ 管理ルール

・ライブラリIDは一度採番したら変更しない。
・欠番が発生しても再利用しない。
・採用・不採用に関係なくライブラリとして保存する。
・演出はライブラリから呼び出して使用する。
・試験機T25をライブラリ検証機とする。
