# YuSosha Design Lab

## Overview

YuSosha Design Lab is a frame design tool for creating original pachislot cabinet shells.

The purpose of this project is to design reusable cabinet frames before implementing HTML/CSS game components.

The tool focuses on:

- Cabinet frame proportions
- Panel layout
- Structural dividers
- Industrial design
- Symmetrical frame editing

This project does NOT generate a complete slot machine.

Only the cabinet shell is designed.

Game components such as reels, buttons, displays and LEDs are added later by HTML/CSS.
