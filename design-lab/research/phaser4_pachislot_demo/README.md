# Phaser 4 Pachislot Expression Demo

Design Lab independent research prototype.

## Purpose
Compare a BASIC pachislot presentation with a FULL presentation using Phaser 4 as an orchestration layer for reel-stop timing, camera motion, layered scene changes, particles, cabinet LEDs, and hit timing.

## Scope
- Phaser 4.2.1 via CDN
- iPhone/Safari-oriented 390px layout
- START -> STOP1 -> STOP2 -> STOP3 interaction
- BASIC/FULL comparison
- No probability model, payout model, production game logic, or Chappy5 dependency
- No modification to the existing Design Lab editor

## Research rule
This directory is disposable/experimental. Successful techniques may later be documented or ported elsewhere only after human evaluation.
